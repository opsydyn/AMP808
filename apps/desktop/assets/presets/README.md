# AMP808-R3TR0 presets

`amp808-first-light.milk` is an original AMP808-R3TR0 preset authored for this repository and
distributed under the repository's MIT licence. It is the compatibility and native-rendering
fixture for ADR-0024. No third-party preset or texture material is included.

ADR-0033 adds a searchable gallery for this built-in preset and for a user-selected local preset
folder. Local files are scanned and loaded in place; they are not copied into AMP808. The
`presets-cream-of-the-crop` collection is not bundled because its current collection-level licence
statement does not provide an unambiguous redistribution grant for most individual files.
